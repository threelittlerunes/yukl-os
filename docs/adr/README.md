# Architecture decision records

One file per decision, `NNN-short-title.md`, numbered with three digits from 001. Statuses: Proposed, Accepted, Rejected, Deprecated, Superseded by ADR NNN.

| Number | Title | Status | Date | Superseded by |
|---|---|---|---|---|

Add one row per ADR when it is created, and update the status column when it changes. A superseded ADR keeps its row and names the ADR that replaced it.
